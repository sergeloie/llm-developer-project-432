# Порог релевантности retrieval — 0.25, а не 0.35

## Контекст

Гибридный поиск (`app/rag/retrieval.py`) отдаёт чанки по косинусному сходству
эмбеддингов. Раньше порог отсечения `RETRIEVAL_THRESHOLD` был 0.35. Для генерации
по **явно заданным документам** порог не используется вообще — берутся все чанки
документа (`retrieve_context_async` в `app/services/rag_pipeline.py`), поэтому
порог влияет только на поиск по свободному запросу (`mode="hybrid"`).

## Решение

`RETRIEVAL_THRESHOLD = 0.25`. Порог — настраиваемая переменная окружения
(`settings.retrieval_threshold`, `app/core/config.py`), значение по умолчанию 0.25,
а не захардкожено в коде поиска.

## Почему

Эмбеддинг-модель по умолчанию — `embeddinggemma-300m`, её косинус для релевантных
пар — примерно 0.4–0.55. При пороге 0.35 similarity-top-k отбрасывал до 75% текста
документа, и модель достраивала карточку из имени файла (баг с `heater_passport`):
в контекст не попадала часть спецификации, и характеристики выдумывались. Для RAG
важен recall — лучше подать лишний чанк, чем потерять спецификацию. Снижение до
0.25 пускает умеренно-близкие пары (0.25–0.4) и отрезает только явный мусор (<0.25).
Лишние чанки всё равно режутся по `CONTEXT_CHAR_LIMIT` в `build_context`, так что
цена recall — только в объёме контекста, не в точности.

## Альтернативы

- Оставить 0.35 — точнее, но теряет спецификацию (наблюдался баг).
- Поднять выше (0.4+) — ещё точнее, ещё больше потерь текста.
- Убрать порог и брать топ-K — теряется фильтрация мусора, который и так попадает
  в топ-K при коротких документах.

## Компромиссы

Ниже порога — больше шума в контексте и выше расход токенов на генерацию. 0.25 —
точка, где recall спецификации восстановлен, а мусор (<0.25) ещё отсекается. Если
сменится эмбеддинг-модель или её размерность (`EMBED_DIM`), порог надо
пересматривать вместе с ней.

## Когда пересматривать

При смене `EMBED_MODEL` / `EMBED_DIM`, при росте доли карточек `needs_review` по
причине низкого покрытия источников (значит, спецификация снова не попадает в
контекст) или при появлении шума в сгенерированных карточках (значит, порог
пропускает мусор).
